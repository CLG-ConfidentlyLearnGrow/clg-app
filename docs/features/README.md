# Feature research briefs

One file per feature, written before the feature is built. Each brief covers:

1. **What it's for**: the problem for students, parents or tutors.
2. **What the evidence says**: findings from Evidence for Learning, AERO or the EEF, with links.
3. **How the design follows the evidence**: the specific choices this leads to.
4. **How we'll know it works**: what the app will measure.
5. **Privacy and child safety**: the data it holds, who sees it, and the rules it touches.
