# How to use the CLG app

Step-by-step guides for each kind of account. Each guide has a contents
list, then short steps with a screenshot for each screen.

| Guide | For |
| --- | --- |
| [Families](families.md) | Parents and carers |
| [Students](students.md) | Students with their own login (usually 13 and over, or tertiary) |
| [Tutors](tutors.md) | CLG tutors |
| [Admins](admins.md) | CLG staff: owner, operations, front desk and finance |

## Screenshots

Screenshots go in `screenshots/`, named as in each guide (for example
`families-01-sign-in.png`). They are taken from the app running with test
data only, never real families' information. Until a screenshot is added,
the guide shows a placeholder line saying what it should show.

## Keeping the guides up to date

When a screen changes, update its steps and retake its screenshot in the
same pull request.
